# Exam Rank 3 Practice 📚

This repository contains a collection of Python solutions aimed at preparing for the **Rank 3** programming exam. Each exercise focuses on core concepts such as algorithms, string manipulation, matrices, and data structures

## 🛠️ Repository Contents

### Basic/Intermediate Level
* **Bracket Validator**: Checks if parentheses, brackets, and braces are correctly balanced.
* **Sort List**: Sorts a list of strings based on length, alphabetical order, and vowel count.
* **Palindrome**: Determines if a string is a palindrome, ignoring spaces, punctuation, and case differences.

### Rank 3 Level
* **Base Converter**: Converts a string-represented number from one base to another (e.g., binary, decimal, hexadecimal).
* **Pattern Tracker**: Counts consecutive digit pairs where the second digit is greater than the first.
* **Mirror Matrix**: Reverses the order of elements in each row of a matrix.
* **Inter**: Returns a string containing characters present in both input strings without duplicates.

### Advanced Level (Rank 4+)
* **Anagram**: Checks if two strings are anagrams, regardless of case or spaces.
* **Shadow Merge**: Merges two integer lists and returns a sorted result.
* **String Sculptor**: Alternates between lowercase and uppercase letters, resetting the pattern after each space.
* **Twister Sequence**: Rotates a list of elements to the right by *n* positions.
* **Whisper Cipher**: Implements a rotation cipher (rot-n style) while preserving non-alphabetic characters.
* **Hidenp**: Checks if the 'small' string is a subsequence of the 'big' string.
